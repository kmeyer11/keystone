# Logos

VfB Stuttgart crest / wordmark / watermark files used as overlays on recap graphics and
video edits.

`vfb-logo2.png` is the active crest — `generate_recap.py` (`CREST_PATH`) loads it directly
by that name. It's the transparent, high-res one; `vfb-logo.png` and `vfb-logo.svg.webp`
are kept as alternates, not currently wired into any script.

Gitignored by content-type (see `.gitignore`): a club crest is trademarked, so keep it out
of a public portfolio repo and store it locally only.
